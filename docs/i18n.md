# Internationalisation (English / Deutsch)

The UI ships in **English** (source language) and **German**. The language follows the
browser (`de-*` → German) on first visit and can be changed any time with the `DE | EN`
button in the top bar or under *Profile → Language*. The choice is stored in
`localStorage` (`pv:locale`) and sets `<html lang>`.

## How it works

`src/app/core/i18n/`

| File | Role |
| ---- | ---- |
| `i18n.service.ts` | `I18nService` — `locale` signal, `t(text, params?)`, sentence-pattern matching |
| `translate.pipe.ts` | `{{ 'Battle Log' \| t }}` · `{{ 'Lv{0}' \| t: [level] }}` (impure: re-renders on switch) |
| `de.ui.ts` | German for template strings (English text → German) |
| `de.data.ts` | German for the remaining strings that live in code |
| `de.data.game.ts` | … in game logic outside the Adventure (battle log, abilities, items, tournaments, spire, odyssey) |
| `de.data.rpg.ts` | … in the Adventure (NPC dialogue, quests, maps) |
| `de.patterns.ts` | Sentences with `{}` slots (see below) |
| `translated-title.strategy.ts` | Translates the document title per route |

The **English text is the key** (gettext style). Anything without an entry falls back to
English, so a half-translated screen never breaks.

### Sentences with dynamic parts

Entries in `DE_PATTERNS` contain `{}` slots, e.g. `['{} fell asleep!', '{} ist eingeschlafen!']`.
They are matched as `(.+?)`; captured pieces (Pokémon names, stats, items) are translated
recursively and substituted by order (`{}`), by name (`{p}`) or by number (`{2}`).
`Speaker: line` strings are translated side by side.

### Adding or changing text

1. Write the English text in the template with the pipe: `{{ 'Hello' | t }}`
   (attributes: `[title]="'Hello' | t"`; with values: `'Hello {0}' | t: [name]`).
2. Add the German to `de.ui.ts` (exact key) — or to the matching `de.data*.ts` for code/data strings. A key may live in only one dictionary file — `i18n:check` fails on duplicates (a later file would silently override an earlier one).
3. `npm run i18n:check` fails when a literal in a template has no German entry (it also
   runs inside `npm run verify` and CI).
4. `PW_CHANNEL=chrome node tools/i18n-scan.mjs` (dev server running) loads every page in
   German and lists text that is still English or has a translation but no `| t`.

### What is intentionally not translated

* Pokémon, move, ability (outside the engine table) and berry names — they come from PokéAPI
  in English. The Pokédex entry (flavour text) and genus **are** shown in German on the
  detail page, quick view and showcase when PokéAPI has them.
* Product names (PokéVerse, PokéAPI, Nuzlocke, Showdown).
